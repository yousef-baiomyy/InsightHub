## Overview

InsightHub is a modern Business Intelligence web application developed to help organizations transform raw sales data into meaningful business insights.

The application combines multiple Excel datasets from different company branches into one unified analytics platform, allowing executives and branch managers to monitor performance, compare branches, track KPIs, and make data-driven decisions through interactive dashboards.

Unlike a traditional dashboard, InsightHub simulates a real-world enterprise reporting solution with role-based access control, executive analytics, AI-generated insights, and professional data visualizations.

The Executive Manager has access to all company data.

Capabilities:

- Compare branch performance
- Executive KPIs
- AI-generated insights
- Revenue analysis
- Profit analysis
- Export reports

```bash

```

Install dependencies


